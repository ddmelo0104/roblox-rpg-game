# Dev: bugs e playtests

- **Bugs** em [`bugs/`](bugs/): um arquivo por bug, a partir de [`templates/bug.md`](../templates/bug.md), com o nome `BUG-NNN-resumo.md`. Os abertos aparecem no [BACKLOG.md](../planejamento/BACKLOG.md#bugs-abertos).
- **Playtests** em [`playtests/`](playtests/): um arquivo por sessão, `AAAA-MM-DD-playtest.md`, com objetivo, observações sem interpretação, feedback dos testadores, bugs encontrados e próximos passos.
